# MakeLRC プロジェクト仕様

## 目的

音声を再生しながら歌詞の行にタイムスタンプを付け、LRC 系の歌詞データを作成・編集するブラウザアプリである。

## 現行機能

- ローカル音声ファイルの読み込みと再生
- 歌詞テキストの入力、行単位の編集
- 現在行の開始・終了タイムスタンプ付与（Space／打刻ボタンの押下と離し）
- 行の追加・削除、現在位置の再設定
- 再生、一時停止、前後移動、Undo/Redo
- Project K Lyrics JSON v1（初期は1トラック）、LRC、Enhanced LRC、WebVTT、SRT 形式への出力
- 詳細モードの終了時刻ポリシー選択（同じ行内のみ補完 / 補完しない）
- 音声テンポ変更（ピッチ維持）とタイミング矛盾の位置付き警告
- 編集中の音声とタイミングの一時保存（`localStorage`）
- MIDI行頭と旧Enhanced LRCを根拠にした、既存Project K JSON用の非破壊タイミング復旧スクリプト

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` | 押下で現在行の開始、離して終了 |
| `Shift + Space` | 再生 / 一時停止 |
| `R` | 現在行のタイムスタンプを再設定 |
| `ArrowUp` / `ArrowDown` | 前 / 次の行へ移動 |
| `J` / `K` | 3 秒戻る / 3 秒進む |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Y` | Redo |
| `?` | ヘルプの表示 / 非表示 |

## データ方針

- 音声はサーバーへアップロードせず、ブラウザ内のローカルデータとして扱う。
- 編集対象は歌詞の行とタイムスタンプである。
- 時刻は音声の再生位置を基準に扱い、キーボード操作の到着時刻を基準にしない。
- 押下から離すまでを1回の打刻として扱い、その間に再生位置・再生状態・テンポ・音源が変わらなかった場合だけ開始・終了時刻をまとめて確定する。
- 打刻中に再生、一時停止、シーク、テンポ変更、音源切替、タブ離脱が発生した場合は、その打刻を破棄する。シーク中は新しい打刻を受け付けない。
- Undo による打ち直し再生は `seeked` 完了後に開始する。
- 出力形式を変更しても、元の行とタイミングの編集状態は保持する。
- Project K JSONの終了時刻は、選択した補完ポリシーに従い、推定値を`exact`と偽らない。
- 詳細モードの「同じ行内のみ」では、行をまたぐ終了時刻補完を行わず、不足時はJSON出力を検証エラーにする。
- 詳細モードの「補完しない」では、終了時刻を自動生成せず、不足時はJSON出力を検証エラーにする。
- Project K JSON の `timingQuality: "mixed"` は文書ルートだけに設定し、行・セグメントは `exact` または `inferred` にする。
- 文字または行の開始時刻が直前の終了時刻より前の場合、画面に対象位置と時刻を警告表示し、JSON出力を検証エラーにする。
- テンポ変更は音声の `playbackRate` を変更し、`preservesPitch` 系の設定でピッチ維持を要求する。

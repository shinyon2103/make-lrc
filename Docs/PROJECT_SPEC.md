# MakeLRC プロジェクト仕様

## 目的

音声を再生しながら歌詞の行にタイムスタンプを付け、LRC 系の歌詞データを作成・編集するブラウザアプリである。

## 現行機能

- ローカル音声ファイルの読み込みと再生
- 歌詞テキストの入力、行単位の編集
- 現在行の開始・終了タイムスタンプ付与（Space／打刻ボタンの押下と離し）
- 行の追加・削除、現在位置の再設定
- 再生、一時停止、前後移動、Undo/Redo
- Project K Lyrics JSON v1（初期は1トラック）、LRC、Enhanced LRC、WebVTT、SRT 形式への出力
- 編集中の音声とタイミングの一時保存（`localStorage`）

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` | 押下で現在行の開始、離して終了 |
| `Shift + Space` | 再生 / 一時停止 |
| `R` | 現在行のタイムスタンプを再設定 |
| `ArrowUp` / `ArrowDown` | 前 / 次の行へ移動 |
| `J` / `K` | 3 秒戻る / 3 秒進む |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Y` | Redo |
| `?` | ヘルプの表示 / 非表示 |

## データ方針

- 音声はサーバーへアップロードせず、ブラウザ内のローカルデータとして扱う。
- 編集対象は歌詞の行とタイムスタンプである。
- 時刻は音声の再生位置を基準に扱い、キーボード操作の到着時刻を基準にしない。
- 出力形式を変更しても、元の行とタイミングの編集状態は保持する。
- Project K JSONの終了時刻は、明示的な離し操作がない場合に次の開始時刻または既定の末尾長から推定し、`timingQuality`を`exact`と偽らない。
